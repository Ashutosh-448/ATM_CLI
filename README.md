# 🏦 National Bank of Akshay - ATM & Banking System

A modern ATM and Banking System built with Python and Tkinter.

## Features

* 🔐 Secure PIN-based Login
* 💰 Check Account Balance
* 📥 Deposit Money
* 📤 Withdraw Money
* 🔁 Fund Transfer
* 📋 Mini Statement
* 🔑 Change PIN
* 🧾 Transaction Receipts
* 💾 JSON-based Data Storage
* 🎨 Modern Dark UI

## Technologies Used

* Python
* Tkinter
* JSON
* Hashlib (SHA-256)
* Object-Oriented Programming (OOP)
